## 已發現風險與處置
1. **備份用到未定義變數**：原版 export 使用 `lexProgress`，import/reset 使用 `LEX_KEY`；已在工作分支改為實際 `lexState / LEX_STORE_KEY`，並納入 `vlState / VL_KEY`。匯入、重置前的安全備份若建立失敗，取消動作。
2. **時區日期**：原版部分單字複習日期採 `toISOString().slice(0,10)`，可能與使用者本地日期不一致；在工作分支將動詞形容詞複習日期改用本地年月日。
3. **教材振假名格式**：原始資料約有 111 個含漢字與假名的複合 ruby 片段，需確認目前 `jpRubyKanjiOnly` 的呈現沒有假名重複、漏標或讀音錯配。此數字是待檢查片段，**不是已證實錯誤數**。
4. **五星紀錄**：文法和英日單字已有跨日/分能力設計，但動詞形容詞的 `lexMark` 仍有同日連答多次快速加星的可能，需要 Phase 3 改成跨日且依題型判定，不可直接覆蓋舊進度。
5. **TTS 依賴瀏覽器聲線**：已有日英語言防護與同步呼叫播放，仍須在 iPhone Safari / Mac Safari / Windows Chrome 實機測試；不能由源碼宣稱音質或成功率完全穩定。
6. **大型單檔結構**：避免一次重構 1.5MB 的程式，後續以獨立模組逐步替換，所有相依功能先納入回歸測試。
