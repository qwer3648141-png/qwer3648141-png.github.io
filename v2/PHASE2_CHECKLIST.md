# ENJP Ocean 2.0 — Phase 2 工作清單

此文件只屬於 `feature/enjp-ocean-v2`，禁止直接合併至 `main`。

## 已確認基準
- 共用既有英文/日文與動詞文法資料，避免重複建立題庫。
- 使用者可選完整學習及快速特訓，學習紀錄共用。
- GitHub Actions 結構檢查已通過；靜態通過不等於手機實機驗收。

## 下一批驗收目標
1. 動詞教室與形容詞教室均有完整學習／快速特訓入口。
2. N5、N4、N3 文法快速特訓可獨立指定等級。
3. 訓練範圍切換後不殘留上一個題目與答案。
4. 漢字上方只標漢字讀音，不重複標原本假名；審查 111 個混合標記片段。
5. 批次複習及五星熟練度需通過跨日、不同題型的測試。
6. 中文例句、日英語音及字體大小需在手機及桌機確認。

## 安全規則
- 每次修改獨立提交並保留原檔案，尤其是進度與備份格式。
- 測試失敗不得合併正式版。
- 在未實測前不得宣稱所有語音／振假名都已修好。
