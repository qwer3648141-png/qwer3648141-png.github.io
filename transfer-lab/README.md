# 授受・借貸動詞研究所｜ENJP Transfer Lab 1.1

這是一個**獨立、單一 HTML 檔案**的日文學習網站，沒有額外的 CSS／JavaScript／CDN 相依檔案，也不會改動 ENJP Ocean 主網站。

## 學習內容

- 動詞圖鑑：10 個核心動詞（借りる、貸す、返す、あげる、くれる、もらう、送る、贈る、渡す、受け取る），各 6 句，合計 60 例句。
- 實用句型：15 個請求、出借、歸還、受惠與禮貌表現。
- 情境對話：4 個主題，每個 4 句，合計 16 句。
- 基礎情境測驗：30 題題庫，支援抽 10／20／30 題及錯題複習。
- 授受進階：10 個「〜てあげる／〜てくれる／〜てもらう」等補助動詞單元、50 個例句、6 組比較、30 題進階測驗；也包含敬語「〜てくださる」「〜ていただく」。
- 日文振假名僅標在漢字上方；例句附中文；使用裝置的日文語音引擎，可調整聲線、語速及自然／讀音模式。

## 開啟方式

1. 可用支援的 GitHub 開發分支預覽服務開啟本資料夾的 `index.html`；第三方預覽是否可用取決於該服務。
2. 也可下載 `index.html`，以電腦瀏覽器開啟，或自行部署至任何靜態網站服務。
3. 教材與測驗內容可離線使用；語音合成是否能離線運作取決於本機已安裝的語音。

## 資料保護

- 學習進度只儲存在這個網站所在瀏覽器的 `localStorage`，key 為 `transferLabV1_localStudy`。
- 語音偏好獨立儲存，key 為 `transferLabV1_audioPreferences`。
- 沒有對外上傳學習紀錄或跨裝置同步，清除瀏覽器網站資料可能使紀錄消失。
- 開發作業限定在 GitHub 分支 `feature/enjp-ocean-v2`；不得修改 `main` 或原版 ENJP Ocean 學習紀錄。
