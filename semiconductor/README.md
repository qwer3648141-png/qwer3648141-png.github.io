# 半導體製程知識庫：晶圓製造全流程

繁體中文入門教材，範圍從矽晶圓製作、FEOL 元件形成、MOL 接觸、BEOL 金屬互連，到晶圓測試與封裝。

- 網頁：[`index.html`](./index.html)
- 導覽順序：總覽流程 → 製程循環 → 溫度與環境 → 各站設備／材料／原理 → 剖面圖 → 原始示意圖及來源
- 主要外部圖解：ASML、Samsung Semiconductor。
- 溫度、氣體及材料是代表範圍與常見例子，不可當作設備 recipe。量產條件依設備、材料、產品與製程整合而異。
- 本頁兩幅 SVG 是概念示意；Samsung 圖片由原站載入，使用者可在圖說處開啟原始教材。
